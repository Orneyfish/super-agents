# sa-core: Replace super-agents' Python with Rust — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Python from the super-agents plugin by moving `scripts/board.py`, `scripts/hookio.py` and the `python3` one-liners into `sa-core`, a small Rust binary. `sa-core` keeps today's command line and output, works on Windows, and ships as verified prebuilt binaries.

**Architecture:** A new crate in `core/` builds one binary, `sa-core`, with `board check|set|scan|root`, `fingerprint`, and `hookio get|emit|status-init|status-set`. A bash launcher, `scripts/sa-native.sh`, picks the binary in this order:
1. `$SUPER_AGENTS_CORE`;
2. a local build in `core/target/release`;
3. a cached copy of the release asset for the plugin's version, downloaded once and checked against `dist/checksums/v<version>.txt` in the repo.

Callers keep using `super-agents board …`, and the hook scripts call `scripts/sa-native.sh hookio …` where they called `scripts/hookio.py`. A hand-run workflow builds five targets into a draft release; the tag workflow checks the drafts against the committed checksums and publishes them.

**Tech Stack:** Rust (edition 2021, 1.89 or newer for `std::fs::File::lock`). Crates: `regex` 1, `serde_json` 1 (with its `preserve_order` feature), `sha2` 0.10, and `tempfile` 3 for tests. Bash plus GNU/BSD-portable tools. GitHub Actions.

Repository: https://github.com/Orneyfish/super-agents. This plan was first written against commit `e93ef43` and is updated for `06e3e63` (plugin version 0.2.0). In the repo this file belongs at `docs/superpowers/plans/2026-11-07-sa-core.md`.

## Global Constraints

- Work on branch `rust-core`. Merge to `main` only after the release in Task 10 is published. Until then, a user installing from `main` would get a launcher with no checksums to download against.
- Minimum Rust version is 1.89 (`rust-version = "1.89"`); file locking comes from `std::fs::File::lock`, so no locking crate is needed.
- Runtime dependencies are exactly `regex = "1"`, `serde_json = "1"` and `sha2 = "0.10"`; the only dev-dependency is `tempfile = "3"`. Task 7 turns on serde_json's `preserve_order` feature (it brings in `indexmap`), because `hookio status-set` must keep a heartbeat's keys in file order, as Python's `dict` does. Adding a crate needs a stated reason in the commit message.
- `board check`, `board set`, `board scan` and `board root` keep board.py's messages and exit codes, and `hookio` keeps hookio.py's stdout byte for byte, apart from the deviations listed under "Behaviour contract" below.
- Prebuilt targets: `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, `x86_64-apple-darwin`, `aarch64-apple-darwin`, `x86_64-pc-windows-msvc`. Asset names: `sa-core-<target>`, plus `.exe` on Windows.
- The only network access is the launcher downloading `sa-core-<target>` for the plugin's own version. A downloaded file whose sha256 does not match `dist/checksums/v<version>.txt` is never run.
- GitHub Actions are pinned by commit: `actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4.4.0`.
- Shell code stays bash plus tools that behave the same on GNU and BSD/macOS. No `python3` and no `jq` anywhere in the plugin, its tests or its workflows when the plan is done.
- `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` and `core/Cargo.toml` carry the same version.
- Before every commit that touches `core/`, run `cargo fmt`, `cargo clippy --locked --all-targets -- -D warnings` and `cargo test --locked` from `core/`, and all three must pass.

## Before you start

**What changed upstream since `e93ef43`.**
- `0cf12f6` removed `jq`. The hook scripts now get and print JSON through `scripts/hookio.py`, so `python3` is the plugin's only runtime dependency, hooks included. Task 7 ports hookio.py and Task 9 points the hook scripts at it.
- `825a0ed` fixed the review findings this plan used to carry. board.py now reports unreadable heartbeats instead of crashing (L6), reads `core.worktree` to find a submodule's checkout (L12), and has a `root` subcommand that `check-evals.sh` and `watchdog-loop.sh` call. The agents and the review-loop skill already say `super-agents board` (L3).

**What the move buys.**
- The board works on Windows: board.py fails there with `ModuleNotFoundError: No module named 'fcntl'`.
- The plugin, hooks included, no longer needs `python3`. The hook scripts then need bash and `sa-core` only. Whether Claude Code's hooks then work on Windows under Git Bash has not been tried.
- `board root` gets one layout right that board.py gets wrong: a repository made with `git init --separate-git-dir` (deviation D3).
- It gives a home for later native code, such as the hook scripts themselves (see Follow-ups).

**What it costs.**
- Five binaries to build per release.
- A download on first use, or a Rust toolchain to build from source. The first use is usually the SessionStart hook, so the download runs inside a hook; `super-agents install-core` does it up front.
- Contributors need Rust to change board or hook-JSON logic.
- Local-path installs must rebuild `core/` after editing it.

**Cheaper option.** If the only goal is running `board.py` on Windows, replacing `fcntl` with a portable lock (`msvcrt.locking`, or a lock file opened with `O_CREAT|O_EXCL`) is about 15 lines of Python. That keeps the `python3` requirement, which the hooks have anyway since `0cf12f6`. This plan is worth it if the goal is a plugin with no interpreter dependency.

**How much of this has been checked:** see the last section, "How much of this has been checked".

## Behaviour contract

These must stay as board.py and hookio.py have them at `06e3e63`. Prompts, the hook scripts, `check-evals.sh`, the watchdog and Claude Code itself depend on them.

| Command | Contract |
|---|---|
| `board check [root]` | Prints `OK: board (N tickets)`, exit 0. Otherwise prints one `FAIL: …` line per problem, exit 1, in this order: missing board; duplicate ids; then for each row: bad status, bad mode, bad Runs, no folder (which skips the remaining checks for that row), RD.md status mismatch, unknown dependency; then folders with no row; then cycles. |
| `board set <NNN\|dir> <status> [root]` | Checks the status first (`status must be one of ('draft', 'ready', 'building', 'done')`, exit 1). A three-digit target is a ticket folder under root; anything else is a directory relative to the current directory. Rewrites the first `**Status:**` line of `RD.md`, or inserts `\n**Status:** <s>\n` after its first line. For `ready`, writes `.evals.sha256` (lowercase sha256 hex of `evals.md` plus `\n`). For a `specs/tickets/NNN-*` folder, rewrites that row's status cell under an exclusive lock. Prints `ok <target> -> <status>`, exit 0; `no such ticket or directory: <target>`, exit 1. |
| `board scan [root]` | Prints one `PROBLEM …` line per problem, or nothing; always exits 0. Order: status files that are not JSON objects (`PROBLEM <file> unreadable: …`, only while some ticket is `building` and not ignored); then for each building ticket: no status file, or per heartbeat blocked, silent (`wait_min` for testing/reviewing, `stale_min` otherwise) and `status file unreadable` for a missing or unusable field, then slow (`slow_min`); then cycles; then the app not answering. Settings come from `.super-agents/watchdog.conf` (`key=value`, `#` comments); a limit that is not a finite number falls back to its default (15, 45, 60). |
| `board root` | Prints the main checkout of the repository around the current directory, exit 0. |
| default `root` | The main checkout, even inside a worktree. |
| `hookio get <a.b.c>` | Reads JSON on stdin and prints the value at that path: a string raw, anything else as compact JSON (`{"k":[1]}`), an empty line for null or a missing path. JSON that does not parse prints nothing on stdout and exits 1. |
| `hookio emit block\|message\|deny\|context <text>` | Prints `{"decision": "block", "reason": t}`, `{"systemMessage": t}`, `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny", "permissionDecisionReason": t}}` or `{"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": t}}`, as Python's `json.dumps(…, indent=2)` writes it: two-space indent, `,` at line ends, `: ` after keys, every character outside printable ASCII as `\uXXXX`. |
| `hookio status-init <ticket> <dir> <phase> <now> <agent>` | Prints the heartbeat `{ticket, dir, phase, started: now, updated: now, note: "", agent}` in that key order, `indent=2`. |
| `hookio status-set <file> <phase> <note> <now>` | Prints `<file>` with `phase`, `note` and `updated` set; existing keys keep their place and new ones go last in that order, `indent=2`. An unreadable file or JSON exits 1. |
| bad arguments | A usage text on stderr, exit 1. |
| sa-core missing or not fetchable | `scripts/sa-native.sh` prints why on stderr and exits 3, never 2: Claude Code treats a hook's exit 2 as blocking (PreToolUse blocks the tool call; Stop and SubagentStop refuse to stop). Each hook script (`session-start`, `eval-gate`, `worker-gate`, `block-code-reads`) first runs `sa-native.sh --version`, and if that fails it exits 0 with a short message and blocks or denies nothing (fail open), as session-start.sh does for a missing `python3` at `06e3e63`. |

**Deliberate deviations** (each one has a test):

| ID | Deviation | Reason |
|---|---|---|
| D1 | Folder lists, duplicate ids, heartbeat files and unreadable status files are processed in sorted order. | board.py uses filesystem order; the watchdog only reports when the output text changes, so the order must be stable. |
| D2 | The reason after `unreadable:` is sa-core's own wording and names the file: `PROBLEM 001 status file unreadable: .job/status-001-a.json: missing 'updated'` where board.py prints `PROBLEM 001 status file unreadable: KeyError('updated')`, and `PROBLEM .job/status-001-a.json unreadable: key must be a string at line 1 column 2` where board.py prints a `JSONDecodeError(…)`. A timestamp must be `YYYY-MM-DDTHH:MM:SS[.fff]` with `Z` or `±HH:MM`; board.py takes anything `datetime.fromisoformat` takes. A limit written with an underscore (`1_0`) falls back to the default; Python's `float` reads it as 10. | Python's exception text is not an interface, and job-status.sh writes only that one timestamp form. |
| D3 | Outside a linked worktree the main checkout is `git rev-parse --show-toplevel`. Inside one it is board.py's answer: the common git dir's `core.worktree` if set, otherwise the common git dir's parent. | board.py uses the second rule everywhere, so in a repository made with `git init --separate-git-dir=<gitdir> <checkout>` it prints the folder around `<gitdir>` instead of `<checkout>`. In a linked worktree of such a repository git records no main checkout, and both print the parent of the git dir. |
| D4 | CRLF files keep CRLF. | board.py rewrites them with the platform's newline. |
| D5 | `app_url` must be `http://`. Connection errors use the OS message; HTTP 400 or higher is still `HTTP Error <code>`. | No TLS stack needed; the app runs on localhost. |
| D6 | The usage text differs (exit code 1 is unchanged), extra arguments get the usage text (board.py ignores them), and an unreadable `BOARD.md` is reported, not a traceback. | |
| D7 | hookio's error messages on stderr differ (exit code 1 is unchanged); a non-integer number may print with other digits (`1e-7` where Python prints `1e-07`); `NaN` and `Infinity` in the input are refused (Python's `json` accepts them); an argument that is not UTF-8 becomes U+FFFD; output lines end in `\n` on Windows too. | serde_json's number formatting and parser; the replies Claude Code reads are strings and objects, which match byte for byte. |

`core/tests/common/mod.rs`:

```rust
//! Helpers shared by the integration tests: run the sa-core binary and build ticket fixtures.
#![allow(dead_code)]

use std::fs;
use std::path::Path;
use std::process::Command;

/// 2026-11-07T10:15:00Z: the clock every test run sees (SA_CORE_NOW).
pub const NOW: u64 = 1_794_046_500;

pub struct Run {
    pub code: i32,
    pub stdout: String,
    pub stderr: String,
}

/// Runs sa-core with `args` in `dir`, with the clock pinned to NOW.
pub fn sa(dir: &Path, args: &[&str]) -> Run {
    let out = Command::new(env!("CARGO_BIN_EXE_sa-core"))
        .args(args)
        .current_dir(dir)
        .env("SA_CORE_NOW", NOW.to_string())
        .output()
        .expect("run sa-core");
    Run {
        code: out.status.code().unwrap_or(-1),
        stdout: String::from_utf8_lossy(&out.stdout).into_owned(),
        stderr: String::from_utf8_lossy(&out.stderr).into_owned(),
    }
}

pub fn s(p: &Path) -> &str {
    p.to_str().expect("utf-8 temp path")
}

pub fn read(p: &Path) -> String {
    fs::read_to_string(p).unwrap()
}

/// specs/tickets/NNN-slug/{RD.md,evals.md}, the same files tests/run.sh writes.
pub fn ticket(root: &Path, nnn: &str, slug: &str, status: &str) {
    let d = root
        .join("specs")
        .join("tickets")
        .join(format!("{nnn}-{slug}"));
    fs::create_dir_all(&d).unwrap();
    fs::write(
        d.join("RD.md"),
        format!("# {slug}\n\n**Status:** {status}\n**Risk:** low\n\n## Functional requirements\n- FR-1: a\n\nUI: no\n"),
    )
    .unwrap();
    fs::write(
        d.join("evals.md"),
        "# E\n\n## E1: a\n- covers: FR-1\n- check: c\n- pass when: p\n- fail when: f\n",
    )
    .unwrap();
}

pub fn board(root: &Path, rows: &str) {
    let d = root.join("specs").join("tickets");
    fs::create_dir_all(&d).unwrap();
    fs::write(
        d.join("BOARD.md"),
        format!("# Board\n| # | Title | Status | Mode | Runs |\n|---|---|---|---|---|\n{rows}"),
    )
    .unwrap();
}

pub const ROWS: &str = "| 001 | Found | draft | team | alongside |\n| 002 | Reset | draft | solo | waits for 001: mailer |\n| 003 | Profile | draft | solo | alongside |\n";

/// Three draft tickets and their board, as in tests/run.sh.
pub fn fixture() -> tempfile::TempDir {
    let t = tempfile::tempdir().unwrap();
    for (nnn, slug) in [("001", "found"), ("002", "reset"), ("003", "profile")] {
        ticket(t.path(), nnn, slug, "draft");
    }
    board(t.path(), ROWS);
    t
}

pub fn git(dir: &Path, args: &[&str]) {
    let out = Command::new("git")
        .args([
            "-c",
            "user.email=t@t",
            "-c",
            "user.name=t",
            "-c",
            "protocol.file.allow=always",
        ])
        .args(args)
        .current_dir(dir)
        .output()
        .expect("run git");
    assert!(
        out.status.success(),
        "git {args:?} failed in {}: {}",
        dir.display(),
        String::from_utf8_lossy(&out.stderr)
    );
}
```

```rust
fn fingerprint_of_a_missing_file_fails() {
```

```rust
//! The main checkout: where BOARD.md and the approved ticket files live, even when a command runs
//! inside a worker's worktree. Outside a linked worktree it is the checkout we are in
//! (`--show-toplevel`), which is right for submodules and `git init --separate-git-dir` repositories
//! too. Inside a linked worktree it is what board.py answers: the `core.worktree` of the common git
//! dir when set (a submodule's git dir lives in `<superproject>/.git/modules/<name>` and records its
//! checkout there), otherwise the parent of the common git dir. board.py uses that rule everywhere,
//! which names the folder around the git dir of a `--separate-git-dir` repository (deviation D3).

use std::path::{Component, Path, PathBuf};
use std::process::Command;

/// The main checkout of the repository around the current directory, or the current directory outside git.
pub fn main_checkout() -> PathBuf {
    let here = std::env::current_dir().unwrap_or_else(|_| PathBuf::from("."));
    let Some(out) = git(&[
        "rev-parse",
        "--path-format=absolute",
        "--git-dir",
        "--git-common-dir",
        "--show-toplevel",
    ]) else {
        return here;
    };
    let mut lines = out.lines();
    let (Some(git_dir), Some(common_dir), Some(top)) = (lines.next(), lines.next(), lines.next())
    else {
        return here;
    };
    if git_dir == common_dir {
        return PathBuf::from(top);
    }
    // a linked worktree: ask the repository it belongs to
    let common = Path::new(common_dir);
    match git(&[
        &format!("--git-dir={common_dir}"),
        "config",
        "--get",
        "core.worktree",
    ]) {
        Some(worktree) => normalize(&common.join(worktree.trim())),
        None => common
            .parent()
            .map_or_else(|| PathBuf::from(top), Path::to_path_buf),
    }
}

/// `a/b/../c` as `a/c`, without touching the filesystem: git's paths are already absolute.
fn normalize(path: &Path) -> PathBuf {
    let mut out = PathBuf::new();
    for part in path.components() {
        match part {
            Component::ParentDir => {
                out.pop();
            }
            Component::CurDir => {}
            other => out.push(other),
        }
    }
    out
}

/// stdout of a successful git command.
fn git(args: &[&str]) -> Option<String> {
    let out = Command::new("git").args(args).output().ok()?;
    out.status
        .success()
        .then(|| String::from_utf8_lossy(&out.stdout).into_owned())
}
```

```rust
/// Ticket numbers in a `waits for NNN, NNN: why` Runs cell (the part before the first colon).

/// Every dependency cycle as "a -> b -> a", found and ordered the way board.py did.
pub fn cycles(rows: &[Row]) -> Vec<String> {
    let mut order: Vec<&str> = Vec::new();
    let mut graph: HashMap<&str, Vec<String>> = HashMap::new();
    for r in rows {
        if !graph.contains_key(r.id.as_str()) {
            order.push(&r.id);
        }
        graph.insert(&r.id, deps(r));
    }
    let mut out = Vec::new();
    let mut seen: HashSet<&str> = HashSet::new();
    for n in &order {
        walk(n, &mut Vec::new(), &graph, &mut seen, &mut out);
    }
    out
}

fn walk<'a>(
    n: &'a str,
    path: &mut Vec<&'a str>,
    graph: &'a HashMap<&'a str, Vec<String>>,
    seen: &mut HashSet<&'a str>,
    out: &mut Vec<String>,
) {
    if let Some(i) = path.iter().position(|p| *p == n) {
        let mut cycle = path[i..].to_vec();
        cycle.push(n);
        out.push(cycle.join(" -> "));
        return;
    }
    if seen.contains(n) || !graph.contains_key(n) {
        return;
    }
    seen.insert(n);
    path.push(n);
    for d in &graph[n] {
        walk(d, path, graph, seen, out);
    }
    path.pop();
}
```

```rust
static STATUS_LINE: LazyLock<Regex> =
    LazyLock::new(|| Regex::new(r"(?m)^\*\*Status:\*\*[^\r\n]*").expect("status line regex"));

/// `board set`: RD.md's Status line, the fingerprint on `ready`, and the board row for a ticket folder.
pub fn set_status(root: &Path, target: &str, status: &str) -> Result<(), String> {
    if !STATUSES.contains(&status) {
        return Err(format!("status must be one of {STATUSES_TEXT}"));
    }
    let is_number = target.len() == 3 && target.bytes().all(|b| b.is_ascii_digit());
    let dir = if is_number {
        ticket_dir(root, target)
    } else {
        Some(PathBuf::from(target))
    };
    let dir = dir
        .filter(|d| d.is_dir())
        .ok_or_else(|| format!("no such ticket or directory: {target}"))?;
    // a ticket folder keeps its board row in sync, however it was named on the command line
    let number = ticket_number(&dir).or_else(|| is_number.then(|| target.to_string()));

    let rd = dir.join("RD.md");
    let text = fs::read_to_string(&rd).map_err(|e| format!("{}: {e}", rd.display()))?;
    let line = format!("**Status:** {status}");
    let updated = if STATUS_LINE.is_match(&text) {
        STATUS_LINE
            .replace(&text, regex::NoExpand(line.as_str()))
            .into_owned()
    } else {
        let nl = if text.contains("\r\n") { "\r\n" } else { "\n" };
        text.replacen(nl, &format!("{nl}{nl}{line}{nl}"), 1)
    };
    fs::write(&rd, updated).map_err(|e| format!("{}: {e}", rd.display()))?;

    // the fingerprint of what the user approved; check-evals.sh --passed compares against it
    let evals = dir.join("evals.md");
    if status == "ready" && evals.exists() {
        let hex = fingerprint(&evals).map_err(|e| format!("{}: {e}", evals.display()))?;
        let fp = dir.join(".evals.sha256");
        fs::write(&fp, format!("{hex}\n")).map_err(|e| format!("{}: {e}", fp.display()))?;
    }

    let board = board_path(root);
    if let Some(number) = number.filter(|_| board.exists()) {
        set_board_row(&board, &number, status).map_err(|e| format!("{}: {e}", board.display()))?;
    }
    Ok(())
}

/// `NNN` when `dir` is a `specs/tickets/NNN-*` folder.
fn ticket_number(dir: &Path) -> Option<String> {
    let dir: PathBuf = dir.components().collect();
    let name = dir.file_name()?.to_str()?;
    let parent = dir.parent()?.file_name()?.to_str()?;
    (parent == "tickets" && is_ticket_name(name)).then(|| name[..3].to_string())
}

/// Rewrites the status cell of row `number` under an exclusive lock: several agents flip rows at once.
fn set_board_row(board: &Path, number: &str, status: &str) -> io::Result<()> {
    let mut file = OpenOptions::new().read(true).write(true).open(board)?;
    file.lock()?; // released when `file` is dropped
    let mut text = String::new();
    file.read_to_string(&mut text)?;
    let row = Regex::new(&format!(
        r"^(\|\s*{number}\s*\|.*?\|\s*)\w+(\s*\|\s*\w+\s*\|)"
    ))
    .map_err(io::Error::other)?;
    let replacement = format!("${{1}}{status}${{2}}");
    let updated: Vec<String> = text
        .split('\n')
        .map(|line| row.replace(line, replacement.as_str()).into_owned())
        .collect();
    file.seek(SeekFrom::Start(0))?;
    file.write_all(updated.join("\n").as_bytes())?;
    let end = file.stream_position()?;
    file.set_len(end)?;
    Ok(())
}
```

```rust
//! Heartbeat timestamps: `YYYY-MM-DDTHH:MM:SS[.fff]` followed by `Z` or `±HH:MM`, the form
//! job-status.sh writes (`date -u +%FT%TZ`). A timestamp without a zone is rejected rather than
//! crashing the scan, which is what board.py did.

use std::time::{SystemTime, UNIX_EPOCH};

/// Seconds since the Unix epoch now. `SA_CORE_NOW=<seconds>` pins it for tests.
pub fn now_unix() -> f64 {
    if let Some(t) = std::env::var("SA_CORE_NOW")
        .ok()
        .and_then(|v| v.parse::<f64>().ok())
    {
        return t;
    }
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs_f64())
        .unwrap_or(0.0)
}

/// Seconds since the Unix epoch, or None when `s` is not a timestamp with a zone.
pub fn parse_unix(s: &str) -> Option<f64> {
    let b = s.as_bytes();
    if b.len() < 20
        || b[4] != b'-'
        || b[7] != b'-'
        || !matches!(b[10], b'T' | b't' | b' ')
        || b[13] != b':'
        || b[16] != b':'
    {
        return None;
    }
    let num = |from: usize, to: usize| -> Option<i64> {
        let part = s.get(from..to)?;
        if part.bytes().all(|c| c.is_ascii_digit()) {
            part.parse().ok()
        } else {
            None
        }
    };
    let (year, month, day) = (num(0, 4)?, num(5, 7)?, num(8, 10)?);
    let (hour, minute, second) = (num(11, 13)?, num(14, 16)?, num(17, 19)?);
    if !(1..=12).contains(&month)
        || !(1..=31).contains(&day)
        || hour > 23
        || minute > 59
        || second > 60
    {
        return None;
    }
    let mut rest = s.get(19..)?;
    let mut fraction = 0.0;
    if let Some(digits_and_zone) = rest.strip_prefix('.') {
        let n = digits_and_zone
            .bytes()
            .take_while(u8::is_ascii_digit)
            .count();
        if n == 0 {
            return None;
        }
        fraction = format!("0.{}", &digits_and_zone[..n]).parse().ok()?;
        rest = &digits_and_zone[n..];
    }
    let offset = match rest {
        "Z" | "z" => 0,
        zone if zone.len() == 6 && zone.as_bytes()[3] == b':' => {
            let sign = match zone.as_bytes()[0] {
                b'+' => 1,
                b'-' => -1,
                _ => return None,
            };
            let (h, m) = (
                zone.get(1..3)?.parse::<i64>().ok()?,
                zone.get(4..6)?.parse::<i64>().ok()?,
            );
            sign * (h * 3600 + m * 60)
        }
        _ => return None,
    };
    let days = days_from_civil(year, month, day);
    Some((days * 86_400 + hour * 3600 + minute * 60 + second - offset) as f64 + fraction)
}

/// Days since 1970-01-01 of a proleptic Gregorian date (Howard Hinnant's `days_from_civil`).
fn days_from_civil(year: i64, month: i64, day: i64) -> i64 {
    let y = if month <= 2 { year - 1 } else { year };
    let era = y.div_euclid(400);
    let yoe = y - era * 400;
    let doy = (153 * ((month + 9) % 12) + 2) / 5 + day - 1;
    let doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
    era * 146_097 + doe - 719_468
}
```

```rust
//! `board scan`: one PROBLEM line per thing the watchdog should look at; no output means healthy.
//! Same checks, messages and order as board.py, including how it treats bad input: a status file
//! that is not a JSON object is reported while any ticket is building, a heartbeat field that is
//! missing or unusable is reported without hiding the other heartbeats, and a watchdog.conf limit
//! that is not a finite number falls back to its default. Heartbeat files are read in sorted order
//! (deviation D1), and the reason after "unreadable:" is sa-core's own wording (D2).

use crate::{board, isotime};
use std::collections::{HashMap, HashSet};
use std::fs;
use std::path::{Path, PathBuf};

/// One heartbeat file. A field that cannot be used keeps the reason as its error.
struct Job {
    file: String,
    who: String,
    phase: Result<String, String>,
    note: String,
    updated: Result<f64, String>,
    started: Result<f64, String>,
}

/// The watchdog's limits in minutes.
struct Limits {
    stale: f64,
    wait: f64,
    slow: f64,
}

pub fn scan(root: &Path) -> Vec<String> {
    let conf = read_conf(root);
    let limits = Limits {
        stale: limit(&conf, "stale_min", 15.0),
        wait: limit(&conf, "wait_min", 45.0),
        slow: limit(&conf, "slow_min", 60.0),
    };
    let skip: HashSet<&str> = conf
        .get("ignore")
        .map(String::as_str)
        .unwrap_or("")
        .split(',')
        .map(str::trim)
        .filter(|x| !x.is_empty())
        .collect();
    let now = isotime::now_unix();

    let mut jobs: HashMap<String, Vec<Job>> = HashMap::new();
    let mut unreadable = Vec::new();
    for path in status_files(root) {
        let file = path
            .strip_prefix(root)
            .unwrap_or(&path)
            .display()
            .to_string();
        match load_job(&path, &file) {
            Ok((Some(ticket), job)) => jobs.entry(ticket).or_default().push(job),
            Ok((None, _)) => {}
            Err(e) => unreadable.push(format!("PROBLEM {file} unreadable: {e}")),
        }
    }

    let rows = board::rows(root);
    let building: Vec<&board::Row> = rows
        .iter()
        .filter(|r| r.status == "building" && !skip.contains(r.id.as_str()))
        .collect();
    let mut out = Vec::new();
    if !building.is_empty() {
        // a file that is not JSON names no ticket, so it only matters while something is building
        out.extend(unreadable);
    }
    for row in building {
        match jobs.get(&row.id) {
            None => out.push(format!(
                "PROBLEM {} is 'building' but has no status file: the worker never started or died",
                row.id
            )),
            Some(js) => job_problems(&row.id, js, &limits, now, &mut out),
        }
    }
    out.extend(
        board::cycles(&rows)
            .into_iter()
            .map(|c| format!("PROBLEM dependency cycle {c}")),
    );
    out
}

/// The problems of one building ticket's heartbeats, checked field by field in board.py's order.
fn job_problems(id: &str, js: &[Job], limits: &Limits, now: f64, out: &mut Vec<String>) {
    let mut started: Vec<(bool, f64)> = Vec::new(); // (still working, minutes since it started)
    for j in js {
        let unreadable = |e: &str| format!("PROBLEM {id} status file unreadable: {}: {e}", j.file);
        let phase = match &j.phase {
            Ok(phase) => phase.as_str(),
            Err(e) => {
                out.push(unreadable(e));
                continue;
            }
        };
        if phase == "blocked" {
            out.push(format!(
                "PROBLEM {id} {} reports blocked: {}",
                j.who, j.note
            ));
        } else if phase != "done" {
            // testing/reviewing: the worker waits on its own tester or reviewer and cannot heartbeat
            let limit = if phase == "testing" || phase == "reviewing" {
                limits.wait
            } else {
                limits.stale
            };
            match &j.updated {
                Ok(t) => {
                    let m = (now - t) / 60.0;
                    if m > limit {
                        out.push(format!(
                            "PROBLEM {id} {} silent for {m:.0} min in phase '{phase}'",
                            j.who
                        ));
                    }
                }
                Err(e) => {
                    out.push(unreadable(e));
                    continue;
                }
            }
        }
        match &j.started {
            Ok(t) => started.push((phase != "done", (now - t) / 60.0)),
            Err(e) => out.push(unreadable(e)),
        }
    }
    if started.iter().any(|(working, _)| *working) {
        let longest = started
            .iter()
            .map(|(_, m)| *m)
            .fold(f64::NEG_INFINITY, f64::max);
        if longest > limits.slow {
            out.push(format!("PROBLEM {id} slow: building for {longest:.0} min"));
        }
    }
}

/// `.super-agents/watchdog.conf`: `key = value` lines; `#` starts a comment line.
fn read_conf(root: &Path) -> HashMap<String, String> {
    let mut conf = HashMap::new();
    if let Ok(text) = fs::read_to_string(root.join(".super-agents").join("watchdog.conf")) {
        for line in text.lines() {
            if line.trim_start().starts_with('#') {
                continue;
            }
            if let Some((k, v)) = line.split_once('=') {
                conf.insert(k.trim().to_string(), v.trim().to_string());
            }
        }
    }
    conf
}

/// A minutes limit from watchdog.conf, or its default when the value is not a finite number:
/// a typo must not silence the watchdog.
fn limit(conf: &HashMap<String, String>, key: &str, default: f64) -> f64 {
    conf.get(key)
        .and_then(|v| v.parse::<f64>().ok())
        .filter(|v| v.is_finite())
        .unwrap_or(default)
}

/// Heartbeat files: solo workers' `.claude/worktrees/*/.job/status*.json`, then team members' `.job/status-*.json`.
fn status_files(root: &Path) -> Vec<PathBuf> {
    let mut files = Vec::new();
    for worktree in entries(&root.join(".claude").join("worktrees")) {
        if name_of(&worktree).starts_with('.') {
            continue;
        }
        files.extend(entries(&worktree.join(".job")).into_iter().filter(|f| {
            let n = name_of(f);
            n.starts_with("status") && n.ends_with(".json")
        }));
    }
    files.extend(entries(&root.join(".job")).into_iter().filter(|f| {
        let n = name_of(f);
        n.starts_with("status-") && n.ends_with(".json")
    }));
    files
}

/// A directory's entries, sorted; none when it cannot be read.
fn entries(dir: &Path) -> Vec<PathBuf> {
    let mut v: Vec<PathBuf> = fs::read_dir(dir)
        .into_iter()
        .flatten()
        .flatten()
        .map(|e| e.path())
        .collect();
    v.sort();
    v
}

fn name_of(p: &Path) -> String {
    p.file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_default()
}

/// A heartbeat file and the ticket it names; an error when it is not a readable JSON object.
fn load_job(path: &Path, file: &str) -> Result<(Option<String>, Job), String> {
    let text = fs::read_to_string(path).map_err(|e| e.to_string())?;
    let value: serde_json::Value = serde_json::from_str(&text).map_err(|e| e.to_string())?;
    let map = value.as_object().ok_or("not a JSON object")?;
    let text = |key: &str| match map.get(key) {
        None => Err(format!("missing '{key}'")),
        Some(serde_json::Value::String(s)) => Ok(s.clone()),
        Some(other) => Err(format!("'{key}' is {other}, not a string")),
    };
    let stamp = |key: &str| {
        text(key).and_then(|t| {
            isotime::parse_unix(&t).ok_or_else(|| format!("bad '{key}' timestamp '{t}'"))
        })
    };
    let job = Job {
        file: file.to_string(),
        who: text("agent")
            .ok()
            .filter(|a| !a.is_empty())
            .unwrap_or_else(|| "worker".to_string()),
        phase: text("phase"),
        note: text("note").unwrap_or_default(),
        updated: stamp("updated"),
        started: stamp("started"),
    };
    Ok((text("ticket").ok(), job))
}
```

```rust
//! The watchdog's "is the main app answering?" probe: one HTTP/1.0 GET with a timeout. http:// only,
//! since the app runs on localhost (deviation D5). Status 400 or higher counts as not answering, as
//! it did with board.py's urllib.

use std::io::{Read, Write};
use std::net::{TcpStream, ToSocketAddrs};
use std::time::Duration;

pub fn probe(url: &str, timeout: Duration) -> Result<(), String> {
    let rest = url
        .strip_prefix("http://")
        .ok_or_else(|| "only http:// URLs are supported".to_string())?;
    let (host, path) = match rest.find('/') {
        Some(i) => (&rest[..i], &rest[i..]),
        None => (rest, "/"),
    };
    if host.is_empty() {
        return Err("no host in the URL".to_string());
    }
    let has_port = host
        .rsplit_once(':')
        .is_some_and(|(_, p)| p.parse::<u16>().is_ok());
    let target = if has_port {
        host.to_string()
    } else {
        format!("{host}:80")
    };
    // try every address, as urllib did: "localhost" may resolve to ::1 first while the app listens on 127.0.0.1
    let mut last = format!("cannot resolve {host}");
    let mut stream = None;
    for addr in target.to_socket_addrs().map_err(|e| e.to_string())? {
        match TcpStream::connect_timeout(&addr, timeout) {
            Ok(s) => {
                stream = Some(s);
                break;
            }
            Err(e) => last = e.to_string(),
        }
    }
    let mut stream = stream.ok_or(last)?;
    stream
        .set_read_timeout(Some(timeout))
        .map_err(|e| e.to_string())?;
    stream
        .set_write_timeout(Some(timeout))
        .map_err(|e| e.to_string())?;
    write!(
        stream,
        "GET {path} HTTP/1.0\r\nHost: {host}\r\nConnection: close\r\n\r\n"
    )
    .map_err(|e| e.to_string())?;
    let mut head = [0u8; 64];
    let n = stream.read(&mut head).map_err(|e| e.to_string())?;
    let status = String::from_utf8_lossy(&head[..n])
        .split_whitespace()
        .nth(1)
        .and_then(|c| c.parse::<u16>().ok())
        .ok_or_else(|| "no HTTP status line in the reply".to_string())?;
    if status >= 400 {
        Err(format!("HTTP Error {status}"))
    } else {
        Ok(())
    }
}
```

```rust
//! The hook scripts' JSON, as scripts/hookio.py wrote it. Claude Code parses these replies, so the
//! bytes match Python's `json.dumps`: `indent=2` for replies and heartbeats, compact for `get`, every
//! character outside printable ASCII escaped as `\uXXXX`, and object keys kept in file order.
//! Error messages differ, and so may the digits of a non-integer number (deviation D7).

use serde_json::{json, Map, Value};
use std::fmt::Write;
use std::fs;
use std::path::Path;

/// `get <a.b.c>`: strings raw, other values as compact JSON, and "" for null or a missing path.
pub fn get(path: &str, input: &[u8]) -> Result<String, String> {
    let doc: Value = serde_json::from_slice(input).map_err(|e| e.to_string())?;
    let mut value = &doc;
    for key in path.split('.').filter(|k| !k.is_empty()) {
        match value.as_object().and_then(|m| m.get(key)) {
            Some(v) => value = v,
            None => return Ok(String::new()),
        }
    }
    Ok(match value {
        Value::Null => String::new(),
        Value::String(s) => s.clone(),
        other => dumps(other, false),
    })
}

/// `emit <kind> <text>`: the reply for that hook event, or None for an unknown kind.
pub fn emit(kind: &str, text: &str) -> Option<String> {
    let reply = match kind {
        "block" => json!({"decision": "block", "reason": text}),
        "message" => json!({"systemMessage": text}),
        "deny" => json!({"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "permissionDecision": "deny",
            "permissionDecisionReason": text,
        }}),
        "context" => json!({"hookSpecificOutput": {
            "hookEventName": "SessionStart",
            "additionalContext": text,
        }}),
        _ => return None,
    };
    Some(dumps(&reply, true))
}

/// `status-init`: a new heartbeat record, as job-status.sh writes it.
pub fn status_init(ticket: &str, dir: &str, phase: &str, now: &str, agent: &str) -> String {
    let record = json!({
        "ticket": ticket,
        "dir": dir,
        "phase": phase,
        "started": now,
        "updated": now,
        "note": "",
        "agent": agent,
    });
    dumps(&record, true)
}

/// `status-set`: `file` with its phase, note and updated time changed; other keys keep their place.
pub fn status_set(file: &Path, phase: &str, note: &str, now: &str) -> Result<String, String> {
    let at = |e: &dyn std::fmt::Display| format!("{}: {e}", file.display());
    let text = fs::read(file).map_err(|e| at(&e))?;
    let mut record: Value = serde_json::from_slice(&text).map_err(|e| at(&e))?;
    let map: &mut Map<String, Value> = record
        .as_object_mut()
        .ok_or_else(|| at(&"not a JSON object"))?;
    for (key, value) in [("phase", phase), ("note", note), ("updated", now)] {
        map.insert(key.to_string(), Value::from(value));
    }
    Ok(dumps(&record, true))
}

/// Python's `json.dumps(value)` with `indent=2` (pretty) or `separators=(",", ":")`, ASCII only.
fn dumps(value: &Value, pretty: bool) -> String {
    let mut out = String::new();
    write_value(&mut out, value, pretty, 0);
    out
}

fn write_value(out: &mut String, value: &Value, pretty: bool, depth: usize) {
    match value {
        Value::Null => out.push_str("null"),
        Value::Bool(b) => out.push_str(if *b { "true" } else { "false" }),
        Value::Number(n) => out.push_str(&n.to_string()),
        Value::String(s) => write_string(out, s),
        Value::Array(items) => {
            let items: Vec<(Option<&str>, &Value)> = items.iter().map(|v| (None, v)).collect();
            write_container(out, ('[', ']'), &items, pretty, depth);
        }
        Value::Object(map) => {
            let items: Vec<(Option<&str>, &Value)> =
                map.iter().map(|(k, v)| (Some(k.as_str()), v)).collect();
            write_container(out, ('{', '}'), &items, pretty, depth);
        }
    }
}

fn write_container(
    out: &mut String,
    (open, close): (char, char),
    items: &[(Option<&str>, &Value)],
    pretty: bool,
    depth: usize,
) {
    out.push(open);
    if items.is_empty() {
        out.push(close);
        return;
    }
    for (i, (key, value)) in items.iter().enumerate() {
        if i > 0 {
            out.push(',');
        }
        if pretty {
            out.push('\n');
            out.push_str(&"  ".repeat(depth + 1));
        }
        if let Some(key) = key {
            write_string(out, key);
            out.push_str(if pretty { ": " } else { ":" });
        }
        write_value(out, value, pretty, depth + 1);
    }
    if pretty {
        out.push('\n');
        out.push_str(&"  ".repeat(depth));
    }
    out.push(close);
}

/// A JSON string the way Python's `ensure_ascii` writes it.
fn write_string(out: &mut String, s: &str) {
    out.push('"');
    for c in s.chars() {
        match c {
            '"' => out.push_str("\\\""),
            '\\' => out.push_str("\\\\"),
            '\n' => out.push_str("\\n"),
            '\r' => out.push_str("\\r"),
            '\t' => out.push_str("\\t"),
            '\u{8}' => out.push_str("\\b"),
            '\u{c}' => out.push_str("\\f"),
            ' '..='~' => out.push(c),
            _ => {
                for unit in c.encode_utf16(&mut [0; 2]) {
                    let _ = write!(out, "\\u{unit:04x}");
                }
            }
        }
    }
    out.push('"');
}
```

```rust
//! scripts' JSON. It replaces scripts/board.py and scripts/hookio.py with the same output and exit
//! codes, except where board.rs, scan.rs and hookio.rs say otherwise.

mod hookio;

mod isotime;
mod scan;

const USAGE: &str = "\
usage: sa-core board check [root]
       sa-core board set <NNN|feature-dir> <draft|ready|building|done> [root]
       sa-core board scan [root]
       sa-core board root
       sa-core fingerprint <file>
       sa-core hookio get <a.b.c>        (reads JSON on stdin)
       sa-core hookio emit <block|message|deny|context> <text>
       sa-core hookio status-init <ticket> <dir> <phase> <now> <agent>
       sa-core hookio status-set <file> <phase> <note> <now>
       sa-core --version
[root] defaults to the main checkout, even inside a worktree.";

fn main() -> ExitCode {
    // a hook can pass any bytes; an argument that is not UTF-8 gets U+FFFD instead of a panic
    let args: Vec<String> = std::env::args_os()
        .skip(1)
        .map(|a| a.to_string_lossy().into_owned())
        .collect();
    let args: Vec<&str> = args.iter().map(String::as_str).collect();
    match args.as_slice() {
        ["--version"] => {
            println!("sa-core {}", env!("CARGO_PKG_VERSION"));
            ExitCode::SUCCESS
        }
        ["fingerprint", file] => match board::fingerprint(Path::new(file)) {
            Ok(hex) => {
                println!("{hex}");
                ExitCode::SUCCESS
            }
            Err(e) => fail(&format!("{file}: {e}")),
        },
        ["board", "check", rest @ ..] if rest.len() <= 1 => {
            let (report, ok) = board::check(&root(rest));
            println!("{report}");
            if ok {
                ExitCode::SUCCESS
            } else {
                ExitCode::FAILURE
            }
        }
        ["board", "set", target, status, rest @ ..] if rest.len() <= 1 => {
            match board::set_status(&root(rest), target, status) {
                Ok(()) => {
                    println!("ok {target} -> {status}");
                    ExitCode::SUCCESS
                }
                Err(message) => fail(&message),
            }
        }
        ["board", "scan", rest @ ..] if rest.len() <= 1 => {
            let problems = scan::scan(&root(rest));
            if !problems.is_empty() {
                println!("{}", problems.join("\n"));
            }
            ExitCode::SUCCESS
        }
        ["board", "root"] => {
            println!("{}", gitroot::main_checkout().display());
            ExitCode::SUCCESS
        }
        ["hookio", "get", path] => {
            let mut input = Vec::new();
            let read = io::stdin().read_to_end(&mut input);
            reply(
                read.map_err(|e| e.to_string())
                    .and_then(|_| hookio::get(path, &input)),
            )
        }
        ["hookio", "emit", kind, text] => match hookio::emit(kind, text) {
            Some(json) => reply(Ok(json)),
            None => fail(USAGE),
        },
        ["hookio", "status-init", ticket, dir, phase, now, agent] => {
            reply(Ok(hookio::status_init(ticket, dir, phase, now, agent)))
        }
        ["hookio", "status-set", file, phase, note, now] => {
            reply(hookio::status_set(Path::new(file), phase, note, now))
        }
        _ => fail(USAGE),
    }
}

/// The optional trailing `[root]` argument, or the main checkout.
fn root(rest: &[&str]) -> PathBuf {
    rest.first()
        .map(PathBuf::from)
        .unwrap_or_else(gitroot::main_checkout)
}

/// A hookio result and a newline, as hookio.py's print wrote it; or `hookio: <error>` and exit 1.
fn reply(result: Result<String, String>) -> ExitCode {
    match result {
        Ok(out) => {
            println!("{out}");
            ExitCode::SUCCESS
        }
        Err(e) => fail(&format!("hookio: {e}")),
    }
}

    eprintln!("{message}");
    ExitCode::FAILURE
```

```bash
#!/usr/bin/env bash
# sa-native.sh <args>: run sa-core, the plugin's native helper, for this machine.
# Order: $SUPER_AGENTS_CORE, a local build (core/target/release), then a cached copy of the release
# asset for this plugin version, downloaded once and checked against dist/checksums/v<version>.txt.
# A download whose sha256 does not match is deleted and never run. Without a usable binary it exits 3,
# never 2: Claude Code reads exit 2 from a hook as "block", and a missing helper must not block anything.
root="$(cd "$(dirname "$(readlink -f "$0")")/.." && pwd)"
case "$(uname -s)-$(uname -m)" in
  Linux-x86_64)               t=x86_64-unknown-linux-musl  x= ;;
  Linux-aarch64|Linux-arm64)  t=aarch64-unknown-linux-musl x= ;;
  Darwin-x86_64)              t=x86_64-apple-darwin        x= ;;
  Darwin-arm64)               t=aarch64-apple-darwin       x= ;;
  MINGW*-x86_64|MSYS*-x86_64) t=x86_64-pc-windows-msvc     x=.exe ;;
  *)                          t=                           x= ;;
esac
build="cargo build --release --locked --manifest-path $root/core/Cargo.toml"
[ -n "${SUPER_AGENTS_CORE:-}" ] && exec "$SUPER_AGENTS_CORE" "$@"
[ -x "$root/core/target/release/sa-core$x" ] && exec "$root/core/target/release/sa-core$x" "$@"
[ -n "$t" ] || { echo "super-agents: no prebuilt sa-core for $(uname -s)-$(uname -m); build it with: $build" >&2; exit 3; }

ver=$(sed -n 's/^ *"version": *"\([^"]*\)".*/\1/p' "$root/.claude-plugin/plugin.json" | head -1)
name="sa-core-$t$x"; dir="${XDG_CACHE_HOME:-$HOME/.cache}/super-agents/$ver"; bin="$dir/$name"
if [ ! -x "$bin" ]; then
  want=$(awk -v f="$name" '$2 == f || $2 == "*" f { print $1 }' "$root/dist/checksums/v$ver.txt" 2>/dev/null)
  [ -n "$want" ] || { echo "super-agents: no checksum for $name in dist/checksums/v$ver.txt; build it with: $build" >&2; exit 3; }
  url="${SUPER_AGENTS_CORE_URL:-https://github.com/Orneyfish/super-agents/releases/download/v$ver}/$name"
  mkdir -p "$dir" && tmp=$(mktemp "$dir/.download.XXXXXX") || exit 3
  if ! curl -fsSL --retry 2 -o "$tmp" "$url"; then
    rm -f "$tmp"; echo "super-agents: could not download $url; build it with: $build" >&2; exit 3
  fi
  got=$( { sha256sum "$tmp" 2>/dev/null || shasum -a 256 "$tmp"; } | awk '{print $1}')
  if [ "$got" != "$want" ]; then
    rm -f "$tmp"; echo "super-agents: checksum mismatch for $url (got $got, want $want); not running it" >&2; exit 3
  fi
  chmod +x "$tmp" && mv -f "$tmp" "$bin" || exit 3
fi
exec "$bin" "$@"
```

```yaml
          GH_TOKEN: ${{ github.token }}
        run: |
          mkdir assets
          gh release download "$GITHUB_REF_NAME" --dir assets --pattern 'sa-core-*'
          (cd assets && sha256sum -c "../dist/checksums/$GITHUB_REF_NAME.txt")
          [ "$(ls assets | wc -l)" -eq "$(wc -l < "dist/checksums/$GITHUB_REF_NAME.txt")" ] || { echo "asset count differs from the checksum list" >&2; exit 1; }
      - name: Publish
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh api "repos/$GITHUB_REPOSITORY/releases/generate-notes" -f tag_name="$GITHUB_REF_NAME" --jq .body > notes.md
          gh release edit "$GITHUB_REF_NAME" --draft=false --notes-file notes.md
```
